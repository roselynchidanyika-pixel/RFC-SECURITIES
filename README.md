# RFC SECURITIES - Cinematic Assets

The 5 cinematic dashboard pictures (one per pillar) are generated
programmatically at first run by `utils/assets_gen.py` into this folder:

| # | Pillar            | Visual               |
|---|-------------------|----------------------|
| 1 | PROFITABILITY DRIVERS | Gold rising line on deep green |
| 2 | CASH FLOW            | Teal green-blue stream curves |
| 3 | INVESTMENT           | Gold geometric growth blocks |
| 4 | RISK & STRESS TEST   | Amber storm bars / stress bands |
| 5 | OPTIMIZATION         | Gold decision-forest paths |

Files generated: `pillar_profitability.jpg`, `pillar_cashflow.jpg`,
`pillar_investment.jpg`, `pillar_risk.jpg`, `pillar_optimization.jpg`,
plus `harare_sunset.jpg` (login background) and `rfc_logo.png`.

If you prefer hand-crafted photographs, replace these files with the same
filenames and the app will use them automatically. Keep a dark-green + gold
grade for consistent theming.
